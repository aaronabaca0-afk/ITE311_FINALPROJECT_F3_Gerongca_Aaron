# MeatLink

**Student Name:** Aaron Gerongca
**Course and Section:** Web System and Technologies 2 (ITE311) - F3

## Project Description
MeatLink is a website that connects local meat suppliers with buyers. Visitors can learn about the service, browse products by category, and send inquiries.

## Technologies Used
- PHP (runs on Laragon)
- HTML5, CSS3, JavaScript
- Git and GitHub

## Running Locally (Laragon)
Place this folder in `C:\laragon\www\meatlink`, start Laragon, then open `http://meatlink.test` or `http://localhost/meatlink`.
